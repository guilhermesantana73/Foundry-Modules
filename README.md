# Foundry-Modules
Módulos para o Foundry com a integração do sistema de Tormenta20.

Todos os módulos me envolvem em algum momento do desenvolvimento, desde da parte mais manual, quanto a administração dos repositórios. 

Apesar de serem "simples", todos os módulos necessitam de aprendizado sobre git, como o github gerencia as branchs e principalmente como ele gerencia Releases.

Aqui temos 4 módulos indexados: 
- Suplementos de Arton
- Bestiário de Arton
- Fullgor dos Deuses
- Coração de Rubi

Cada um desses tem o seu próprio README bem detalhado nos repositórios respectivos.
